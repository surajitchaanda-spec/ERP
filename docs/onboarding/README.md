# School Onboarding Guide

This guide provides standard operating procedures (SOPs) and suggested training assets for rolling out the ERP platform to new schools.

## Overview

1. **Kickoff Call (Week 0)** — Introduce stakeholders, confirm goals, review data migration timeline.
2. **Data Collection (Weeks 1-2)** — Share secure SFTP workspace and templates for student, staff, and course data.
3. **Sandbox Training (Week 3)** — Provide sandbox credentials and schedule live training using the materials below.
4. **Go-Live Preparation (Week 4)** — Finalize integrations, enable monitoring dashboards, and distribute support contacts.

## Success Metrics

- 100% of staff invited and active before go-live.
- Baseline attendance data validated for the first week.
- Support SLAs agreed upon and documented in Zendesk.

## Feedback Loop

- Capture feedback in the onboarding project board.
- Schedule a post-implementation review within 30 days of go-live.
