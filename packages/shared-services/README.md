# Shared Services Library

Centralized API, configuration, and localization services shared by ERP applications.

## Features

- Environment configuration helpers for aligning monitoring and error reporting endpoints.
- Axios API client factory with token injection and error callbacks.
- Lightweight translation utilities for Node.js and React Native contexts.

## Development scripts

- `npm run build --workspace @erp/shared-services`
- `npm run lint --workspace @erp/shared-services`
- `npm run test --workspace @erp/shared-services`
